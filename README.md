# LowKey Mini OS

простая мини ос для красоты и кастоминга.
это заставка/бут-скрин, не полноценная операционная система.

## что это

- бутлоадер на ассемблере
- ядро на чистом си
- текстовый режим с цветами
- легко менять логотип и цвета

## структура проекта

```
boot.asm          - загрузчик (не трогать если не знаете)
kernel.c          - основной код (здесь кастомите)
kernel_entry.asm  - точка входа (не трогать)
Makefile          - сборка
```

## как кастомить

### поменять цвета

открой `kernel.c` и измени defines в начале:

```c
#define COLOR_BORDER     0x0b    /* голубой -> поменяй на свой */
#define COLOR_TITLE      0x0f    /* белый */
#define COLOR_SUBTITLE   0x0a    /* светло-зелёный */
```

коды цветов (0x0 + цвет):
- 0 = чёрный
- 1 = синий
- 2 = зелёный
- 3 = голубой
- 4 = красный
- 5 = пурпурный
- 6 = коричневый
- 7 = серый
- 8 = тёмно-серый
- 9 = светло-синий
- a = светло-зелёный
- b = светло-голубой
- c = светло-красный
- d = светло-пурпурный
- e = жёлтый
- f = белый

### поменять текст логотипа

в `kernel.c` найди функцию `draw_logo()` и меняй строки в `print_at()`.

### поменять позицию логотипа

```c
#define LOGO_ROW         10      /* строка (0-24) */
#define LOGO_COL         25      /* колонка (0-79) */
```

## сборка и запуск

требуется: nasm, gcc, ld, qemu

```bash
# собрать
make

# запуск в qemu (консоль)
make run

# запуск с окном
make run-gui

# очистка
make clean
```
