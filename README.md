# LowKey Mini OS

простая мини ос для красоты и кастоминга.
это заставка/бут-скрин, не полноценная операционная система.

## что это

- полностью на ассемблере (больше контроля)
- бутлоадер + ядро в текстовом режиме
- легко менять цвета, текст, позиции
- компилируется одной командой

## структура проекта

```
boot.asm          - загрузчик (512 байт, не трогать)
kernel.asm        - всё остальное (кастомь здесь)
Makefile          - сборка
```

## как кастомить

всё настраивается в `kernel.asm` в секции "настройки кастомизации":

### цвета
```asm
COLOR_BORDER    equ 0x0b      ; голубой рамка
COLOR_TITLE     equ 0x0f      ; белый заголовок
COLOR_SUBTITLE  equ 0x0b      ; голубой подзаголовок
COLOR_ACCENT    equ 0x0e      ; жёлтый акцент
COLOR_FOOTER    equ 0x07      ; серый текст снизу
```

коды цветов: 0=чёрный, 1=синий, 2=зелёный, 3=голубой, 4=красный, 5=пурпурный, 6=коричневый, 7=серый, 8=тёмно-серый, 9=светло-синий, a=светло-зелёный, b=светло-голубой, c=светло-красный, d=светло-пурпурный, e=жёлтый, f=белый

### позиция логотипа
```asm
LOGO_ROW        equ 8         ; строка (0-24)
LOGO_COL        equ 20        ; колонка (0-79)
```

### рамка
```asm
BORDER_CHAR_H   equ '-'       ; горизонталь
BORDER_CHAR_V   equ '|'       ; вертикаль
BORDER_CHAR_CORNER equ '+'    ; углы
```

### текст логотипа
внизу `kernel.asm` найди секцию со строками:
```asm
.line1: db " текст ", 0
.line2: db " текст ", 0
```
меняй текст в кавычках. для псевдографики используй `0xdb`, `0xde`, `0xdf`.

## сборка и запуск

требуется только: nasm, qemu

```bash
make         # собрать
make run     # запуск в qemu (консоль)
make run-gui # запуск с окном
make clean   # очистка
```
